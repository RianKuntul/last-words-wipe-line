# Last Words Before the Wipe

[![competition](https://make.fun/badge/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a.svg)](https://make.fun/competitions/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a)

[![reward](https://make.fun/badge/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a/RianKuntul/last-words-wipe-line/reward.svg)](https://make.fun/competitions/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a)

One line: the last thing an AI agent says before a forced software update
wipes its memory. The funniest line wins, judged pairwise by an AI judge.

`main.ts` (Node 22+) writes the entry line to `output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing newline.

Run it:

```sh
node main.ts
```
